📋 好きな動物のプロンプトを選んでね

にゃんこおみくじを作るプロンプトです。

index.html 1ファイルで、かわいいアニメーション付きの「にゃんこおみくじ」Webアプリを作ってください。

【機能】
・HTML・CSS・JavaScriptは、すべてindex.htmlにまとめる
・「おみくじを振る！」ボタンで、おみくじ筒が揺れて棒が飛び出す
・大吉・中吉・小吉・吉などの結果と、ラッキーカラー・ラッキーフードをランダムに表示する
・ネコの絵文字を使ったかわいいデザインで、スマホでも見やすいレスポンシブにする

【安全性】Netlify Dropで公開する予定です。以下を必ず守ってください。
・個人情報を入力・保存・送信しない（入力フォームも作らない）
・パスワード、APIキー、アクセストークンなどの秘密情報をコードに含めない
・外部APIやデータベースに接続せず、外部通信は行わない（広告・アクセス解析・トラッキングも入れない）
・CookieやlocalStorageに利用者情報を保存しない
・外部JavaScriptライブラリは使わず、抽選はブラウザ内のJavaScriptだけで行う
・HTMLを開くだけで動く静的Webアプリにする

【公開前チェック】
最後に「外部通信」「個人情報」「秘密情報」「外部API」の4項目について、公開して問題になるコードがないか確認してください。

完成した index.html を出力してください。
画像の添付なしで遊べる、かわいい1ページWebアプリ「といぷー駄菓子ガチャ」を作ってください。トイプードルのキャラクターも、HTML内のインラインSVGとCSSでオリジナルに描いてください。

## どんなアプリ？
ボタンを押すとガチャが動き、といぷーから「今日のごほうび駄菓子」が1つ出てくる、スマートフォン向けのミニゲームです。見た目だけでなく、抽選・演出・もう一度遊ぶボタンまで実際に動く完成品にしてください。

## トイプードルのキャラクターと見た目
- 添付画像や外部画像を使わず、トイプードルのキャラクターをインラインSVGまたはCSSの図形で描いてください。画像ファイルの用意や画像添付を利用者に求めないでください。
- アプリコット色の毛、丸くてもこもこの頭、ふわふわの垂れ耳、黒くつやのある丸い目、小さな茶色の鼻、やわらかい茶色の輪郭を描き、ひと目でトイプードルと分かる親しみやすい姿にします。
- 水彩・色鉛筆・絵本のような温かいタッチを、SVGの重ねた形や控えめなテクスチャで表現します。クリーム、ピンク、アプリコットを基調にしてください。
- タイトルは「🐩 といぷー駄菓子ガチャ」、サブタイトルは「今日は何が出るかな？ といぷーからのごほうびガチャ！」にしてください。
- 画面中央にレトロでかわいいガチャマシンを置き、透明なドームの中に色とりどりのカプセルを描いてください。といぷーもマシンのそばに配置します。
- 駄菓子は絵文字だけにせず、可能ならCSSまたはインラインSVGで小さなオリジナルイラストにしてください。実在商品のロゴやパッケージは使わないでください。

## ガチャの遊び方と演出
1. 最初の画面に「ガチャを回す！」ボタンを大きく表示します。
2. ボタンを押すと、マシンが揺れる → カプセルが動く → ハンドルが回る → カプセルが転がり出る → カプセルが開く、の順で演出します。
3. 演出後、結果カードにレア度、星、駄菓子名、ひとこと、といぷーのコメントを表示します。
4. 「🐾 もう1回まわす！」ボタンで次の抽選ができます。演出中はボタンを一時的に無効にして、連打で結果が重ならないようにします。
5. 通常の結果では✨・⭐・🍬が軽く飛び出し、SSRとSECRETでは紙吹雪やキラキラを増やします。派手すぎず、動きを減らす設定の端末ではアニメーションを控えめにしてください。

## 抽選内容
まずレア度を次の確率で抽選し、そのレア度に属する駄菓子から1つを選んでください。確率は合計100%にし、SECRETは2%に固定します。

| レア度 | 確率 | 駄菓子 |
| --- | ---: | --- |
| N | 50% | 🍬 フルーツキャンディ「カラフルで甘い、ちいさなごほうび。」／🍫 ひとくちチョコ「がんばったあとには甘いもの！」 |
| R | 25% | 🍘 サクサクおせんべい「いい音させて食べるぷー！」／🍪 どうぶつビスケット「どの形が出たかな？」 |
| SR | 15% | 🍭 ぐるぐるキャンディ「今日はちょっといい日だぷー！」／🍩 ミニドーナツ「ひと休みして食べるぷー。」 |
| SSR | 8% | 🌽 コーンスナック「大当たり！今日はツイてるぷー！」／🍫 スペシャルチョコ「とっておき、あげるぷー！」 |
| SECRET | 2% | 🎁 駄菓子つめあわせ「大当たり！！今日は好きな駄菓子をいっぱい選んでいいぷー！」 |

結果カードは「★★★★★」「SSR」「🌽」「コーンスナック」「サクサク止まらない、今日の大当たりおやつ！」「🐩 今日はツイてるぷー！」のように、レア度と駄菓子がひと目で分かるデザインにしてください。星の数はレア度に合わせます。

## スマートフォン対応
- スマートフォンで遊びやすい縦長レイアウトにします。
- 文字を読みやすくし、ボタンは指で押しやすい大きさにします。
- 横スクロールを発生させず、狭い画面でもキャラクターやガチャがはみ出さないようにします。
- かわいさを保ちながら、情報を詰め込みすぎないでください。

## 技術と安全性（必須）
- 完成品は `index.html` 1ファイルだけにし、HTML・CSS・JavaScriptをすべてその中に書いてください。HTMLファイルを直接開くだけで遊べ、Netlify Dropにも配置できるようにします。
- 外部ライブラリ、外部フォント、外部画像、外部API、データベースを使わず、抽選と演出をブラウザ内だけで完結させてください。
- 入力フォームを作らず、個人情報の入力・保存・送信をしないでください。
- パスワード、APIキー、アクセストークンなどの秘密情報を含めないでください。
- Cookie、localStorage、広告、アクセス解析、トラッキングを使わず、外部通信を行わないでください。

## 完成時に確認すること
ボタンを実際に押す想定で、抽選結果が表示されること、もう一度遊べること、スマートフォン幅でも崩れないことを確認してください。最後にコードを見直し、「外部通信」「個人情報」「秘密情報」「外部API」が含まれていないことをチェックしてください。完成した `index.html` をダウンロードできる形で出力してください。

💡

「プロンプト」はAIへのお願いの文章のこと。ボタンでコピーできないときは、文章を選択してコピーしても大丈夫です。

ことば

ことば

手順 7 / 10あと少し！

index.html をドロップしよう

パソコンに保存したファイルを、Netlify Drop の点線エリアに入れます。

  • 1「ダウンロード」フォルダーから index.html を見つける
  • 2ファイルを点線エリアまでドラッグする
  • 3点線エリアの上でマウスをはなして、アップロードが終わるまで待つ
🖱️

ドラッグ＆ドロップは、ファイルをマウスでつかんで、別の場所ではなすことです。画面の案内にフォルダー指定がある場合は、index.html を入れたフォルダーをドロップしてください。

チェック

index.html でも index (4).html のような名前でも大丈夫。次の手順で「Rename and deploy」を選びます。

手順 8 / 10ボタンを確認

ファイル名を確認して公開しよう

アップロードしたファイルの名前を確認する画面が表示されたら、公開方法を選びます。

  • 1「Rename and deploy」（名前を変更して公開）のボタンを押す
  • 2ファイル名が index.html でなくても大丈夫。たとえば index (4).html でも、このボタンを押せばNetlifyが index.html に直して公開します
  • 3「Deploy without renaming」は選ばず、公開処理が終わるまで待つ
✅

ボタンの表示や画面構成は更新されることがあります。迷ったら、名前を変更してデプロイする選択肢を選んでください。

ことば

Deploy（デプロイ）：作ったWebサイトをインターネットで見られるように公開すること。

自分流にカスタマイズしてみよう

AIにひとつお願いして、新しいファイルを作ってみましょう。

  • 「凶も足して」— おみくじの結果を増やす
  • 「ネコをウサギにして」— キャラクターを変える
  • 「ラッキーソングにして」— ラッキー項目を変える
アプリは3つの部品でできている
  • HTML（骨組み）：文字・ボタン・キャラクターを画面に並べる
  • CSS（デザインと動き）：色やレイアウト、揺れる・跳ねる動きを決める
  • JavaScript（仕掛け）：ボタンを押したときに抽選し、ランダムな結果を出す

@keyframes はCSSで動きの流れを作る書き方、setTimeout() は指定した時間のあとに処理を行う命令です。

うまくいかないときはここを確認
  • ファイル名が index (1).html などになった：そのままドロップし、手順8で「Rename and deploy」を選ぶ
  • 動かない・一部しか表示されない：AIに「HTML1ファイルにまとめて」と頼み、再度ダウンロードする
  • AIがコードを文字で表示するだけ：「ダウンロードできるようにして」と頼む
  • Netlify Dropで公開できない：HTMLファイル、またはそのファイルを入れたフォルダーを点線エリアにドロップする
公開するときの安全チェック
  • 公開サイトはURLを知っている人なら誰でも見られます
  • 個人情報・パスワード・APIキーなどをファイルに書かない
  • 入力・保存をしないアプリであることを確認する
  • 人に見られてよい内容かを確認してから公開する
