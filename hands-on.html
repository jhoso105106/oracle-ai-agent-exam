ハンズオンの進み具合 1 / 8

手順 1 / 8まずは準備

AIのチャット画面を開こう

文章でお願いすると、答えてくれるチャットAIを使います。使いやすいものをひとつ選びましょう。

  • 1ChatGPT・Microsoft Copilot・Gemini のどれかを開く
  • 2アカウントへのサインインを求められたら、画面の案内に従う
  • 3文字を入力できるチャット画面が表示されたら準備OK！
💬 ChatGPT ↗https://chatgpt.com/ 🌈 Copilot ↗https://copilot.microsoft.com/ ✨ Gemini ↗https://gemini.google.com/
ことば

チャットAI：文章でお願いすると、答えを返してくれるサービスのこと。

手順 2 / 8コピーするだけ

プロンプトをコピーしよう

下の文章をぜんぶコピーします。このお願いの文章を、AIにそのまま使います。

📋 プロンプト（コピー用）
index.html という1つのファイルで、かわいいアニメーション付きの「にゃんこおみくじ」Webアプリを作ってください。

・HTML・CSS・JavaScript を、すべて1つのファイルにまとめてください。
・「おみくじを振る！」ボタンを押すと、筒が揺れて棒が飛び出すようにしてください。
・大吉・中吉・小吉などの結果と、ラッキーカラー・ラッキーフードをランダムに表示してください。
・ネコの絵文字が上下に動き、結果が出たらキラキラが飛ぶようにしてください。
・パステルカラーで、スマートフォンでも見やすくしてください。
・完成したら、index.html をダウンロードできるようにしてください。

💡

「プロンプト」はAIへのお願いの文章のこと。ボタンでコピーできないときは、文章を選択してコピーしても大丈夫です。

ことば

コピー：文章を覚えさせて、別の場所に貼り付けられるようにすること。

手順 3 / 8AIにお願い

AIに貼り付けて送ろう

さきほど開いたAIのチャット画面に、コピーした文章を貼り付けて送ります。

  • 1チャット画面の入力欄をクリックする
  • 2貼り付ける（Windowsは Ctrl + V ／ Macは Command + V）
  • 3送信ボタンを押して、AIが作り終わるまで少し待つ
⏳

AIがコードを作り始めます。長い返事が出ても大丈夫です。「ダウンロード」や「index.html」が表示されるか確認しましょう。

ことば

貼り付け（ペースト）：コピーした文章を、入力欄に入れること。

手順 4 / 8パソコンに保存

index.html をダウンロードしよう

AIの返事から完成したファイルを見つけて、パソコンに保存します。

  • 1AIの返事の中にある index.html を探す
  • 2ダウンロードボタンを押して、保存先を確認する（通常は「ダウンロード」フォルダー）
  • 3ファイル名が index.html になっているか確認する
🆘

ダウンロードボタンが見つからないときは、AIに「index.html をダウンロードできるようにしてください」と頼んでみましょう。

ことば

ダウンロード：インターネット上のファイルを、自分のパソコンに保存すること。

手順 5 / 8できたかチェック

パソコンで動きを確かめよう

公開する前に、自分のパソコンでアプリを開いて試します。

  • 1保存した index.html をダブルクリックする
  • 2Chrome や Edge などのブラウザーで開く
  • 3「おみくじを振る！」ボタンを押して、結果が出るか試す
🐾

ネコやおみくじが動いて、運勢・ラッキーカラー・ラッキーフードが表示されたら成功です！何度か押して、結果が変わるかも試してみましょう。

ことば

ブラウザー：Webサイトを見るためのアプリ。Chrome や Edge などがあります。

手順 6 / 8公開の準備

Netlify Drop を開こう

ファイルを置くだけでWebサイトを公開できるサービス、Netlify Dropを使います。

  • 1下のボタンから Netlify Drop を開く
  • 2画面に「Drag and drop your site folder here」のような点線エリアを探す
  • 3画面に案内が出た場合は、サインインなど必要な準備をする
Netlify Drop を開く ↗
🔒

公開すると、URLを知っている人が誰でも見られます。個人情報・パスワード・APIキーがファイルに入っていないか、公開前に確認しましょう。

ことば

Netlify Drop：ファイルやフォルダーを置いて、Webサイトを公開できるサービス。

手順 7 / 8あと少し！

index.html をドロップしよう

パソコンに保存したファイルを、Netlify Drop の点線エリアに入れます。

  • 1「ダウンロード」フォルダーから index.html を見つける
  • 2ファイルを点線エリアまでドラッグする
  • 3点線エリアの上でマウスをはなして、アップロードが終わるまで待つ
🖱️

ドラッグ＆ドロップは、ファイルをマウスでつかんで、別の場所ではなすことです。画面の案内にフォルダー指定がある場合は、index.html を入れたフォルダーをドロップしてください。

チェック

ファイル名が index.html になっているか、もう一度確認してからドロップ！

手順 8 / 8完成！

公開されたURLを開こう

アップロードが終わると、Webサイトの住所であるURLが表示されます。

  • 1表示されたURLをクリックして、公開サイトを開く
  • 2公開されたページでも「おみくじを振る！」を押してみる
  • 3うまく動いたら、URLを友だちに送ってみよう！
https://あなたのサイト名.netlify.app
🌍

URLを知っている人なら誰でも見られます。人に見られてもよい内容か、確認してから公開・共有しましょう。
